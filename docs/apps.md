# Desktop and Android apps

Both apps work on their own (a **local account**: everything stays on the device) or with your server
(a **server account**: the data is on your Motus server; the app and the exercise photos stay on the device).
Both kinds can be added side by side and switched in Settings → Accounts on this device.

## Install

From the [latest release](https://github.com/userofit123/motus/releases/latest):

- **Android:** `motus-x.y.z.apk`. Allow "Install unknown apps" for your browser or file manager when asked.
- **Linux:** `.AppImage`, `.deb` or `.rpm`.
- **Windows:** the `.exe` installer.

## Updates

- The apps check GitHub for a new version (Settings → Updates) and can download it automatically.
- Desktop: the update installs when you restart the app (or press Install).
- Android: Android always asks you to confirm an install; Motus downloads the APK, checks it, and opens the installer.
  The first time, Android asks you to allow Motus to install apps.
- Alternative for Android: [Obtainium](https://github.com/ImranR98/Obtainium) can follow the GitHub releases.

The repository has to be public for the apps to see new releases.

## Backups

- Desktop: to `Documents/Motus Backups` (change it in Settings → Backup & restore).
- Android: to `Documents/Motus` on the phone.
